================================================================
  核心功能 (23个命令)
================================================================

✅ 成员管理 (7个)
   - /mute <成员> [时间]     禁言用户
   - /kick <成员>            踢出成员
   - /kick <时间>            踢出不活跃成员
   - /ban <成员>             封禁用户
   - /unban <QQ号>           解除封禁
   - /op <成员>              设置管理员
   - /deop <成员>            取消管理员

✅ 消息管理 (2个)
   - /recall                 撤回被回复的消息
   - /recall <数量>          批量撤回消息

✅ 广告系统 (5个)
   - /ad                     发布广告
   - /ad set <文本>          保存广告
   - /ad clear               清空广告
   - /ad reset               恢复默认
   - /adban [on/off]         广告拦截开关

✅ 欢迎系统 (5个)
   - /wel                    手动欢迎
   - /wel set <文本>         设置欢迎
   - /wel on/off             开关欢迎
   - /wel reset              恢复默认
   - /wel status             查看状态

✅ 头衔管理 (2个)
   - /title @成员 <文本>     设置头衔
   - /title unset @成员      取消头衔

✅ MC工具 (2个)
   - /slimefinder <v> <seed> 史莱姆查找
   - /sf                     缩写命令

================================================================
  广告检测算法
================================================================

评分机制:
  广告短语 ........ 3分 (加微信、代理、赚钱等)
  联系方式 ........ 4分 (微信号、QQ号)
  手机号码 ........ 3分 (1xxxxxxxxxx)
  外部链接 ........ 2分 (http://...)
  促销词汇 ........ 2分 (优惠、限时等)

判定阈值: ≥ 6分 → 判定为广告
处理方式: 自动撤回 + 禁言10分钟
