# ZM-QQManager

> 功能强大的 QQ 群管理插件，为 AstrBot 提供全方位的群管理功能

## ✨ 功能特性

### 🔨 成员管理
- **禁言管理**: 支持灵活的时间单位（天/周/月/年）
- **踢出成员**: 踢出指定成员或清理不活跃用户
- **封禁系统**: 永久封禁用户，自动拒绝加群申请
- **管理员管理**: 设置或取消群管理员权限

### 💬 消息管理
- **消息撤回**: 支持撤回指定消息或批量撤回
- **消息记录**: 自动记录群消息，支持回溯撤回

### 🛡️ 广告拦截
- **智能检测**: 基于评分机制的广告检测系统
- **自动处理**: 检测到广告后自动撤回并禁言
- **多维度判断**: 综合分析广告短语、联系方式、外链等特征

### 📢 群公告与欢迎
- **自定义广告**: 保存和发布群内广告
- **入群欢迎**: 自动欢迎新成员，支持自定义文本
- **占位符支持**: 支持 `{at}`, `{name}`, `{user_id}`, `{group_id}` 占位符

### 🎮 特色工具
- **群头衔管理**: 设置或取消群成员专属头衔
- **史莱姆查找器**: 我的世界史莱姆区块查找工具

## 📖 命令列表

### 成员管理命令

#### `/mute <成员> [时间]`
禁言群内用户

**参数**:
- `<成员>`: @用户 或 QQ号
- `[时间]`: 可选，格式为 `数字+单位`，支持 `d`(天)、`w`(周)、`m`(月)、`y`(年)

**示例**:
```
/mute @张三 30d      # 禁言30天
/mute 123456 1w     # 禁言1周
/mute @李四         # 禁言默认时长
```

#### `/kick <成员>`
踢出指定群成员

**示例**:
```
/kick @张三
/kick 123456
```

#### `/kick <时间>`
踢出群内指定时间内未发言的成员

**示例**:
```
/kick 20d    # 踢出20天没发言的成员
/kick 1m     # 踢出1个月没发言的成员
```

#### `/ban <成员>`
封禁用户并踢出，之后自动拒绝其加群申请

**示例**:
```
/ban @张三
/ban 123456
```

#### `/unban <QQ号>`
从封禁列表移除用户

**示例**:
```
/unban 123456
```

#### `/op <成员>`
给用户设置群管理员权限

**示例**:
```
/op @张三
/op 123456
```

#### `/deop <成员>`
取消用户的群管理员权限

**示例**:
```
/deop @张三
```

### 消息管理命令

#### `/recall`
回复消息后使用，撤回被回复的消息

**示例**:
```
[回复某条消息]
/recall
```

#### `/recall <数量>`
撤回插件运行期间记录的近期群消息

**示例**:
```
/recall 5    # 撤回最近5条消息
/recall 10   # 撤回最近10条消息
```

**注意**: 受 QQ 可撤回时限（2分钟）和机器人权限限制

### 广告管理命令

#### `/ad`
发布本群已保存的广告

#### `/ad set <文本>`
保存广告内容

**示例**:
```
/ad set 欢迎大家来到本群！
/ad set 本群禁止广告，违者封禁
```

#### `/ad clear`
清空本群广告

#### `/ad reset`
恢复默认广告

#### `/adban`
切换广告拦截开关（开启/关闭）

#### `/adban on`
开启广告拦截

#### `/adban off`
关闭广告拦截

**广告检测机制**:
- 广告短语（如"加微信"、"代理"等）: 3分
- 联系方式（微信号、QQ号等）: 4分
- 手机号: 3分
- 外链: 2分
- 促销词汇: 2分
- **总分 ≥ 6 分**: 判定为广告，自动撤回并禁言10分钟

### 欢迎消息命令

#### `/wel`
手动执行一次欢迎消息

#### `/wel set <文本>`
保存欢迎内容并开启自动欢迎

**示例**:
```
/wel set 欢迎 {at} 加入本群！请阅读群公告
/wel set 欢迎新成员 {name} (ID: {user_id})
```

#### `/wel on`
开启自动入群欢迎

#### `/wel off`
关闭自动入群欢迎

#### `/wel reset`
恢复默认欢迎内容

#### `/wel status`
查看欢迎消息状态和内容

### 群头衔命令

#### `/title @成员 <文本>`
设置群成员专属头衔

**示例**:
```
/title @张三 超级管理员
/title @李四 活跃成员 {user_id}
```

#### `/title unset @成员`
取消成员的群专属头衔

**示例**:
```
/title unset @张三
```

**注意**: QQ 通常只允许群主执行此操作

### 我的世界工具

#### `/slimefinder <version> <seed>`
查找史莱姆区块（也可使用缩写 `/sf`）

**参数**:
- `<version>`: 游戏版本（如 1.20.1）
- `<seed>`: 世界种子（整数）

**示例**:
```
/slimefinder 1.20.1 12345678
/sf 1.19.4 -9876543210
```

## 🔧 占位符说明

在广告、欢迎消息、头衔等文本中，支持以下占位符：

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `{at}` | @该用户 | @张三 |
| `{name}` | 用户昵称 | 张三 |
| `{user_id}` | 用户QQ号 | 123456 |
| `{group_id}` | 群号 | 789012 |

**使用示例**:
```
/wel set 欢迎 {at} 加入本群！
/wel set 欢迎 {name} (QQ: {user_id}) 加入群 {group_id}
/title @用户 {name}的专属头衔
```

## 📦 安装方法

### 方法 1: AstrBot 插件市场（推荐）

1. 打开 AstrBot WebUI 管理面板
2. 进入「插件市场」页面
3. 搜索 `ZM-QQManager`
4. 点击「安装」按钮

### 方法 2: 手动安装

1. 下载本插件
2. 将整个 `ZM-QQManager` 文件夹放入 AstrBot 的 `plugins` 目录
3. 重启 AstrBot

### 方法 3: Git 安装

```bash
cd /path/to/astrbot/plugins
git clone https://github.com/yourusername/ZM-QQManager.git
```

## ⚙️ 配置说明

插件使用 AstrBot 的 KV 数据库存储配置，按群独立保存：

- **封禁列表**: `zm_qqmanager_banlist_{群号}`
- **广告内容**: `zm_qqmanager_ad_{群号}`
- **欢迎消息**: `zm_qqmanager_welcome_{群号}`
- **广告拦截开关**: `zm_qqmanager_adban_{群号}`

所有配置通过命令设置，无需手动编辑配置文件。

## 🔒 权限要求

为了正常使用所有功能，机器人需要以下权限：

- ✅ 群管理员或群主权限（用于禁言、踢人等操作）
- ✅ 消息撤回权限
- ✅ 设置管理员权限（仅群主）
- ✅ 设置群头衔权限（仅群主）

**注意**: 部分功能（如设置头衔）需要机器人具有群主权限。

## 📊 数据持久化

- ✅ 封禁列表永久保存，重启不丢失
- ✅ 广告和欢迎消息配置永久保存
- ⚠️ 消息历史记录仅保存在内存中，重启后清空（每群最多保存100条）
