# ZM-QQManager

> 功能强大的 QQ 群管理插件，为 AstrBot 提供全方位的群管理功能

## ✨ 功能特性

### 🔨 成员管理
- **禁言管理**: 支持灵活的时间单位（秒/分/时/天/周）
- **禁言列表**: `/mutelist` 查看在禁成员及各自剩余时长
- **全体禁言**: `/muteall` 一键全群禁言，不带参数默认永久
- **踢出成员**: 踢出指定成员或清理不活跃用户
- **封禁系统**: 永久封禁用户，自动拒绝加群申请
- **管理员管理**: 设置或取消群管理员权限

### 💬 消息管理
- **消息撤回**: 支持撤回指定消息或批量撤回
- **消息记录**: 自动记录群消息，支持回溯撤回
- **合并转发**: `/merge` 构造任意合并聊天记录

### 🚫 敏感词与刷屏
- **敏感词拦截**: 命中后自动撤回并禁言，时长可按群设置
- **三种词源**: 仅自定义词 / 远程词库 / 两者混合
- **白名单**: 修正误伤，命中白名单不处理
- **刷屏检测**: 滑动窗口条数 + 连续重复内容双重判定
- **名片检测**: 检测群名片中的广告与敏感内容

### 📁 文件仓库
- **限时下载**: 上传文件并按需签发限时下载链接
- **更新日志**: 以合并转发形式查看版本更新记录

### ☠️ 赛博击杀
- **跨群播报**: 在与该成员的共同群同步提醒管理处理
- **模板可配**: 播报文案在后台插件配置中修改

### 🛡️ 广告拦截
- **智能检测**: 基于评分机制的广告检测系统
- **自动处理**: 检测到广告后自动撤回并禁言
- **多维度判断**: 综合分析广告短语、联系方式、外链等特征

### 📢 群公告与欢迎
- **自定义广告**: 保存和发布群内广告
- **入群欢迎**: 自动欢迎新成员，支持自定义文本
- **占位符支持**: 支持 `{at}`, `{name}`, `{user_id}`, `{group_id}` 占位符

### 🎮 特色工具
- **群头衔管理**: 设置或取消群成员专属头衔
- **史莱姆查找器**: 我的世界史莱姆区块查找工具

## 📖 命令列表

### 成员管理命令

#### `/mute <成员> [时间]`
禁言群内用户

**参数**:
- `<成员>`: @用户 或 QQ号
- `[时间]`: 可选，格式为 `数字+单位`，支持 `d`(天)、`w`(周)、`m`(月)、`y`(年)

**示例**:
```
/mute @张三 30d      # 禁言30天
/mute 123456 1w     # 禁言1周
/mute @李四         # 禁言默认时长
```

#### `/kick <成员>`
踢出指定群成员

**示例**:
```
/kick @张三
/kick 123456
```

#### `/kick <时间>`
踢出群内指定时间内未发言的成员

**示例**:
```
/kick 20d    # 踢出20天没发言的成员
/kick 1m     # 踢出1个月没发言的成员
```

#### `/ban <成员>`
封禁用户并踢出，之后自动拒绝其加群申请

**示例**:
```
/ban @张三
/ban 123456
```

#### `/unban <QQ号>`
从封禁列表移除用户

**示例**:
```
/unban 123456
```

#### `/op <成员>`
给用户设置群管理员权限

**示例**:
```
/op @张三
/op 123456
```

#### `/deop <成员>`
取消用户的群管理员权限

**示例**:
```
/deop @张三
```

#### `/mutelist`
查看本群当前被禁言的成员及各自剩余时长

**示例**:
```
/mutelist
```

#### `/muteall [时长]`
全体禁言。不带参数默认永久，`off` 解除

**示例**:
```
/muteall        # 永久全体禁言
/muteall 30m    # 全体禁言 30 分钟
/muteall 2h     # 全体禁言 2 小时
/muteall off    # 解除全体禁言
```

### 消息管理命令

#### `/recall`
回复消息后使用，撤回被回复的消息

**示例**:
```
[回复某条消息]
/recall
```

#### `/recall <数量> [是否包含机器人]`
撤回群内最近若干条消息。优先向协议端拉取群历史记录，
所以机器人自己发的消息、插件启动前的消息同样能撤回；
协议端不支持 `get_group_msg_history` 时退回插件内存中的记录。

**示例**:
```
/recall 5          # 撤回最近 5 条消息
/recall 20         # 撤回最近 20 条消息
/recall 20 false   # 撤回最近 20 条，但不含机器人自己的消息
```

执行后会逐条撤回并汇报结果，例如
`撤回完成：成功 18 条，失败 2 条（共 20 条）`，
失败条目会附上消息 ID、发送者和协议端返回的原因（详情同时写入日志）。

**注意**: 机器人需要**群管理员或群主**权限。管理员撤回他人消息没有时限；
2 分钟时限只作用于普通成员撤回自己的消息。

### 广告管理命令

#### `/ad`
发布本群已保存的广告

#### `/ad set <文本>`
保存广告内容

**示例**:
```
/ad set 欢迎大家来到本群！
/ad set 本群禁止广告，违者封禁
```

#### `/ad clear`
清空本群广告

#### `/ad reset`
恢复默认广告

#### `/adban`
切换广告拦截开关（开启/关闭）

#### `/adban on`
开启广告拦截

#### `/adban off`
关闭广告拦截

**广告检测机制**:
- 广告短语（如"加微信"、"代理"等）: 3分
- 联系方式（微信号、QQ号等）: 4分
- 手机号: 3分
- 外链: 2分
- 促销词汇: 2分
- **总分 ≥ 6 分**: 判定为广告，自动撤回并禁言10分钟

#### `/wel set <文本>`

开启自动入群欢迎

#### `/wel off`
关闭自动入群欢迎

#### `/wel reset`

#### `/wel status`
查看欢迎消息状态和内容

### 敏感词命令

命令全称 `/sensitive-words`，缩写 `/sw`，两者等价。

#### `/sw on [时长]` / `/sw off`
开启或关闭本群敏感词拦截。时长**默认单位为分钟**。

修改时长需要先关闭再重新开启：

```
/sw on          # 开启，使用后台默认时长
/sw on 10       # 开启，命中禁言 10 分钟
/sw off         # 关闭
/sw on 20       # 再次开启并改为 20 分钟
```

#### `/sw add <文本>` / `/sw del <文本>`
增删自定义敏感词

```
/sw add 代练
/sw del 代练
```

#### `/sw mode <custom|library|both>`
选择词源：仅自定义词、仅远程词库、两者混合

```
/sw mode custom     # 只用管理员添加的词
/sw mode library    # 只用远程词库
/sw mode both       # 混合（默认）
```

#### `/sw list` / `/sw reload`
查看词库状态 / 重新拉取远程词库

### 刷屏与名片检测

#### `/antiflood on|off`
开关本群刷屏检测。判定阈值（窗口秒数、条数、重复次数、禁言时长）在后台配置。

#### `/cardcheck on|off`
开关群名片检测。违规处理方式（warn / reset / mute / kick）在后台配置。

### 文件仓库命令

#### `/file upload <name> <时长>`
上传文件。执行后**紧接着发送文件**（一般为 zip）即可入库，
`<时长>` 为下载链接有效期。

```
/file upload guoclient 3m
```

在群里上传时，机器人接收文件成功后会把文件从群里清掉：

- 机器人是**群主**：撤回该文件消息（并顺带尝试删除群文件）
- 机器人是**群管理员**：直接删除群文件中的该文件
- 机器人**既不是群主也不是群管理员**：提示上传失败，文件不入库

#### `/file download <name>`（简写 `/f dl <name>`）
获取该文件的临时下载链接，有效期为上传时设定的时长。全体成员可用，
但**只能私聊机器人使用**：在群里发下载指令时，机器人只回复提示语
（默认「需要私聊才可以下载」，可用 `file_private_only_tip` 自定义）。

```
/f dl guoclient
```

链接过期或失效后，访问该链接的网页会显示「链接已失效」，
提示语可用 `file_link_expired_tip` 自定义。

#### `/file log <name> [次数]`
以合并转发形式查看最近若干条更新记录，标题为 `<name>近<次数>更新记录`。
没有记录时返回`暂无更新记录`；实际记录不足请求条数时返回现有全部。

```
/file log guoclient 20
```

#### `/file log update <name> <版本> <说明>`
记录一次版本更新。版本可为文本或数字，不作限制。

```
/file log update guoclient 1.2.0 修复登录闪退
```

#### `/file list` / `/file delete <name>`
查看仓库全部文件 / 删除文件

### 合并转发命令

#### `/merge <标题> <QQ> <内容> [<QQ> <内容> ...]`
构造一条合并聊天记录。可追加多组 `<QQ> <内容>` 表示多个发送者。

```
/merge 乐子 3332 你是傻逼吗
/merge 对话记录 10001 在吗 10002 不在
```

### 赛博击杀命令

#### `/kill <成员> <理由>`
在机器人与该成员的共同群内同步播报，提醒管理处理。
播报文案在后台插件配置 `kill_template` 中修改，
可用占位符：`{at}` `{target}` `{name}` `{reason}` `{operator}` `{group_id}`。

```
/kill @张三 发布广告
/kill 123456789 恶意刷屏
```

### 帮助命令

#### `/zmhelp`
查看全部命令总览

## 🔧 占位符说明

在广告、欢迎消息、头衔等文本中，支持以下占位符：

| 占位符 | 说明 | 示例 |
|--------|------|------|
| `{at}` | @该用户 | @张三 |
| `{name}` | 用户昵称 | 张三 |
| `{user_id}` | 用户QQ号 | 123456 |
| `{group_id}` | 群号 | 789012 |

**使用示例**:
```
/wel set 欢迎 {at} 加入本群！
/wel set 欢迎 {name} (QQ: {user_id}) 加入群 {group_id}
/title @用户 {name}的专属头衔
```

1. 下载本插件

3. 重启 AstrBot

```bash
cd /path/to/astrbot/plugins
git clone https://github.com/yourusername/ZM-QQManager.git
```

## ⚙️ 配置说明

运行数据按群独立保存在插件数据目录下（封禁列表、广告与欢迎文本、
各功能开关、自定义敏感词、文件仓库与更新日志等），通过命令设置即可。

后台插件配置面板可调整的项目包括：

- **刷屏判定**: `flood_threshold`、`flood_window`、`flood_repeat_limit`、
  `flood_mute_duration`、`flood_recall`、`flood_tip`
- **敏感词**: `sensitive_default_duration`、`sensitive_library_urls`、
  `sensitive_whitelist`、`sensitive_tip`
- **名片检测**: `card_check_enabled`、`card_ad_threshold`、`card_action`、
  `card_mute_duration`、`card_tip`
- **广告拦截**: `ad_threshold`、`ad_mute_duration`、`ad_tip`
- **文件服务**: `file_server_enabled`、`file_host`、`file_port`、
  `file_base_url`、`file_default_ttl`、`file_private_only_tip`、
  `file_link_expired_tip`
- **赛博击杀**: `kill_template`、`kill_notify_all_groups`

## 🔒 权限要求

**命令权限**: 管理类命令仅 AstrBot 管理员可用。
面向全体群成员开放的只有 `/file download`、`/file list`、`/file log`（查看）
与 `/zmhelp`。

为了正常使用所有功能，机器人需要以下群权限：

- ✅ 群管理员或群主权限（用于禁言、踢人等操作）
- ✅ 消息撤回权限
- ✅ 设置管理员权限（仅群主）
- ✅ 设置群头衔权限（仅群主）

**注意**: 部分功能（如设置头衔）需要机器人具有群主权限。

### 下载服务安全说明

内置下载服务不做身份校验，仅凭一次签发的限时令牌访问，且不提供目录浏览。
`file_host` 默认 `0.0.0.0`（监听所有网卡）。若不需要公网访问，
建议改为 `127.0.0.1`，或通过防火墙/反向代理限制来源。

## 📊 数据持久化

- ✅ 封禁列表永久保存，重启不丢失
- ✅ 广告和欢迎消息配置永久保存
- ⚠️ 消息历史记录仅保存在内存中，重启后清空（每群最多保存100条）
